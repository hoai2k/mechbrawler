# JJK Brawler II

A cursed-energy platform fighter. Plain HTML/CSS/JS — no build step, no dependencies.
Served from `index.html`; game code lives in `src/`, tooling in `tools/`.

## Merge policy

All work is meant to land on `main`. When a change is complete, don't stop at a
feature branch — open a pull request against `main` and merge it once checks pass.
Assume this is the default for every task in this repo; it does not need to be
restated in the prompt.

If a change should *not* be merged (experiment, spike, request for review only),
the prompt will say so explicitly.
