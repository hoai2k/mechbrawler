Mechs are standing in a neutral gait frame, not the move's own pose: outside the gaits, most rig states are still mis-mapped (K5, open) and would show a machine on its face. A ruler is all the reference has to be to answer a size question — switch to Launch state above to see the mapping as it stands.

Each card renders the real rig, in the real animation state the move plays, frozen at release — so the size of a drawing is a ratio you can see rather than a number you have to trust. Art no kit throws (hazards, statuses, the KO burst) gets the roster's median mech beside it, dimmed, purely as a ruler.

Drag the canvas to nudge the drawing, scroll it to size it, double-click a control to put it back. The red shape is what the move actually collides on and the green cross is where it leaves the mech — neither is editable, because both are numbers the kit declares; they are here to be matched. When it looks right, Copy config and paste the result over EFFECT_PLACEMENT in src/config_effects.js.
